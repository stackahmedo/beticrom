# Beticorm Halal Market (ベティコルム・ハラール市場)

High-performance e-commerce storefront for authentic halal groceries, fresh meats, frozen food, and pantry essentials in Japan.

## Overview
Beticorm Halal Market delivers verified halal food products across Japan with temperature-segregated logistics (Dry, Cool, Frozen) via Yamato Transport. The catalog features over 900 authenticated products, real-time multilingual support, and domestic Japanese payment methods.

## Tech Stack
- **Core:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS, PostCSS
- **Icons & UI:** Lucide React, Radix UI Primitives
- **Logistics:** Yamato Cool TA-Q-BIN temperature split fee logic

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

## Features
- **948 Verified Products:** Full catalog with images, categories, and inventory metrics.
- **Trilingual Storefront:** Seamless switching between Japanese (日本語), English, and Bengali (বাংলা).
- **Cold-Chain Segregated Cart:** Automatic grouping for Dry, Cool, and Frozen items with Yamato delivery rules.
- **Multilingual Search:** Instant search and category filtering with auto-suggestions.
- **Domestic Payment Options:** Credit Card (Stripe), PayPay, Konbini payment, Bank Transfer, and Cash on Delivery.
